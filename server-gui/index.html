固定ポートを設定すると、全拠点のメディア(UDP/TCP)がこの1ポートに集約され、 UTM側の許可設定が「サーバーIP宛 TCP 3000 + UDP/TCP 固定ポート」だけで済みます。 追加TCP待受はSFUへの直接ICE-TCPであり、HTTPS/TURN-TLSではありません。直接接続を制限する UTM拠点には、許可されやすい TURN-TLS（例: turns:ホスト名:443?transport=tcp）を併用してください。 「設定を保存して配信」を押すとサーバーが自動再起動して適用されます。
サーバー再起動時刻 指定時刻にサーバープロセスを再起動します。終了後は自動復帰し、各拠点は自動再接続します（断は数秒）
クライアント再起動時刻 全拠点へ同期され、各クライアントが指定時刻にアプリを再起動します（通話・画面共有中の拠点は終わってから実行）
時刻は「HH:MM」の24時間表記です（サーバー/各拠点PCのローカル時刻で判定）。空欄で無効。 サーバーとクライアントの時刻は数分ずらすことを推奨します（例: サーバー 04:00、クライアント 04:05）。 「設定を保存して配信」で保存され、接続中の全拠点へ即時同期されます。 ※この設定はこのサーバー機にのみ保存されます。バックアップ構成では、 メイン/サブ両方のサーバーGUIに同じ時刻を設定してください（拠点は接続中の サーバーの設定に従うため、片方だけだと接続先によって実施されない夜が生じます）。
