# MeetingViewer

SFUサーバーから映像・音声を受信するだけの閲覧専用アプリです。

## 動作

- カメラ/マイクを取得しません。
- SFUサーバーにはProducerを作成せず、既存拠点のProducerだけをconsumeします。
- 拠点端末が増減した場合、1秒間隔の同期で表示を追従します。
- リモート映像が瞬断した場合、最後に正常受信したフレームを最大20秒間表示します。新しいフレームを確認できればライブ表示へ戻り、20秒を超えれば保持画像を破棄して「映像なし」へ移ります。意図的なカメラOFFには適用しません。

## 起動

```bash
npm install
npm run electron:dev
```

## ビルド

```bash
npm run package
```
